Declined route ends here. A daily check-in needs a confirmed habit. Use 'Start the habit after all' in the phone to continue.

  1. No dashboard and no onboarding. Starters are shortcuts into the same conversation, not separate modes. Free text is the main input. The prototype prefills the scripted question; it does not interpret free text. 'Daily check-in' jumps ahead to state 8.

  2. The game is optional. 'Show the amount' and a typed 'just show me' go straight to the answer. A declined game is not offered again in this conversation. Nothing about the answer is shown yet.

  3. The guess is committed before the reveal. Slider and number field show the same value. The fixed 0–200 € range is a design proposal: the range must not leak the answer. The prototype presets 20,00 € for the scenario; production should start with no preset value. The composer stays active, so the user can change topic.

  4. Amounts come from application code, not from model text. Feedback thanks the user for taking part. It makes no improvement claim: one guess is not a trend. The reveal is readable without animation. The ride list is the evidence.

  5. The three baskets are taught in context, with the user's own data. Basket assignment is an interpretation that the user can correct. Scripted free-text example: the user adds context in their own words.

  6. Sponky proposes; only the user's confirmation changes the reading. One purchase at a time. 'Keep as it is' is shown but not wired.

  7. The correction changes the coaching interpretation only. The historical total stays 60,00 €. 45,00 € is 'potentially flexible', not 'unnecessary'.

  8. The result updates immediately when the slider moves. Three things stay separate: historical spending, projected savings, and money actually saved. The card states which rides are included.

  9. Only this confirmation saves the habit. One tracked category or action and one optional goal. No reminder-time picker. Goal amounts, points, and the missed-day rule are open proposals (see README). Add a goal under Edit to see the goal row in state 8.

  10. Accept and decline are both valid endings of this state. Declining saves nothing and is not offered again in this conversation.

  11. Clearly simulated next day: the date control is outside the phone. The 7,00 € ride is a separate return-day fixture. Any reflection answer completes the check-in. The streak rewards the reflection, not lower spending.

  12. The streak advances once per completed check-in date. Reopening, replaying a game, or ordinary chat does not add credit (see the 'Already completed today' variant). Streak start and missed-day behaviour are open proposals.
